# KTV Booking – Tài liệu dự án

Hệ thống đặt phòng karaoke trực tuyến cho chuỗi KTV nhiều chi nhánh.

| Thông tin         | Giá trị                                  |
| ----------------- | ---------------------------------------- |
| Team              | 4 người (2 Backend, 2 Frontend)          |
| Thời gian         | 4 tuần                                   |
| Nền tảng          | Website                                  |
| Frontend          | React + TypeScript                       |
| Backend           | Java 21 + Spring Boot 3                  |
| Database          | PostgreSQL 16                            |
| Tính năng nổi bật | Sơ đồ phòng real-time + giữ chỗ tạm thời |
